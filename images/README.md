# Images

Every `<img>` / background in `index.html` points to a descriptive filename.
To update the site, **overwrite the file and keep the same name** (if you switch a
file's extension, update its `src` in `index.html`).

- **Photos** (`.jpg`): royalty-free stock from Unsplash (Unsplash License &ndash; free
  for commercial and non-commercial use, no permission or attribution required;
  crediting the photographer is appreciated). Sourced from unsplash.com.
- **Logo & architecture diagram** (`.svg`): custom, made for this project.
- **Technology icons** (`.svg`): official brand marks from Simple Icons
  (https://simpleicons.org, CC0), each wrapped on a white circle.
- **Team headshots** (`.jpg`): still placeholders &ndash; add real photos.
